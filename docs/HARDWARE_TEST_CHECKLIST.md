# Real-device checklist (do this at least a day before the presentation)
Computer ↔ phone, repeat for each pairing you plan to use (Windows+Android, Ubuntu+iPhone, ...).

- [ ] Desktop installer runs without errors; window says “Ready – visible as SlideLink-…”
- [ ] Phone app lists the computer within 10 s; tap → code prompt → connected
- [ ] Test Connection shows OK (< 500 ms)
- [ ] Open PDF (20+ pages): next/prev/first/last/go-to, counter matches, black/white, fullscreen, laser
- [ ] Other viewer (PowerPoint/Okular): next/prev/start/exit work
- [ ] Open MP4 via the desktop button: phone switches to video; play/pause/±10 s/volume/mute/seek/fullscreen/next
- [ ] Walk 8 m away, come back: auto-reconnect works
- [ ] Turn phone Bluetooth off/on: reconnects
- [ ] Close/reopen desktop app: phone reconnects without asking for code
- [ ] Lock phone screen for 1 min (iOS may suspend BLE – keep screen awake during the talk)
- [ ] 30-minute soak with next/prev every few seconds: no dropouts
Report failures (OS versions, adapter model, error text) and I will fix them.
